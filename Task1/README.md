# TASK-1 Sample Superstore Dataset Analysis

## Project Title

Sample Superstore Data Analysis and Visualization Using Python

## Objective

The objective of this project is to analyze the Sample Superstore dataset using Python libraries and understand sales, profit, discount, product categories, data distribution, and relationships between numerical variables through data analysis and visualization.

## Libraries Used

* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

* Dataset Name: Sample Superstore
* File Format: CSV

## Tasks Performed

* Imported the required Python libraries.
* Loaded the Sample Superstore dataset using Pandas.
* Displayed the first few records using `head()`.
* Checked the dataset structure and data types using `info()`.
* Generated descriptive statistics using `describe()`.
* Converted Order Date and Ship Date into datetime format.
* Calculated Delivery Days using Order Date and Ship Date.
* Identified unique product categories.
* Checked for missing values in the dataset.
* Calculated total sales by category using Pandas GroupBy.
* Created a bar plot to analyze sales by category.
* Created a histogram to analyze sales distribution.
* Created a bar plot to compare profit by category.
* Created a bar plot to analyze sales distribution by category.
* Created a box plot to analyze overall profit distribution.
* Created a box plot to analyze profit variation across categories.
* Checked the unique discount values.
* Created a scatter plot to analyze the relationship between discount and profit.
* Selected numerical columns for correlation analysis.
* Calculated the correlation matrix.
* Created a correlation heatmap to visualize relationships between numerical variables.

## Data Analysis

### Sales Analysis

Sales were analyzed to understand the total sales generated by different product categories and the overall distribution of sales values.

### Profit Analysis

Profit was analyzed across categories and through box plots to understand profit distribution, variation, and possible outliers.

### Discount Analysis

The relationship between discount and profit was analyzed using a scatter plot to identify possible patterns between the two variables.

### Correlation Analysis

A correlation matrix and heatmap were used to understand the relationships between numerical variables in the dataset.

## Visualizations

* **Bar Plot:** Used to compare sales and profit across categories.
* **Histogram:** Used to understand the distribution of sales.
* **Box Plot:** Used to analyze profit distribution, variation, and outliers.
* **Scatter Plot:** Used to study the relationship between discount and profit.
* **Correlation Heatmap:** Used to visualize relationships between numerical variables.

## Output

The project successfully analyzed the Sample Superstore dataset and generated multiple statistical results and visualizations for understanding sales, profit, discount, distributions, and correlations.

## Conclusion

This project helped in understanding how Python libraries can be used for **data preprocessing, exploratory data analysis, statistical analysis, and data visualization**. The analysis provides a better understanding of sales and profit performance in the Sample Superstore dataset and demonstrates the practical use of Python for analyzing real-world business data.
